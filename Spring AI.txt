Spring AI
----------

What is Spring AI?
- framework for integrating AI into Spring applications
- Simplifies adding gen AI using Spring's modular, POJO based design
- Connects enterprose data and APIs with AI models seamlessly

Core Features
-------------
- Multi-Provider Support:
	- Integrates with OpenAI, Anthropic, AWS, Google, Hugging Face for chat, embeddings, text-to-image, audio and moderation

- MCP support:
	- Allows building MCP clients and servers easily

- Vector Store Integrations
	- Supports RAG with Pinecone, Redis, PostGreSQL/ pgVector, MongoDB, etc

- Advanced Patterns
	- Chat memory, tool/ function calling,a nd Advisors API for resuable AI logic

- Observability & Guardrails
	- Monitors AI operations and evaluates outputs to ensure reliability
	
Spring Ecosystem Integrations
-----------------------------
- Spirng Boot:
	- auto-configuration and starters for quick setup with AI models and vector DBs

- Familiar Model:
	- uses Spring's depenedency injection and abstarction, nehaves liek any Spring Bean

- Modular:
	- easily swap AI proviers or vector stores without chnaging core logic

Typical Use Cases
-----------------
- AI powered customer support
	- build intelligent assistants with conversation memory and API integration

- Natural language search over documents
	- Summarize or query proprietary data using RAG and vector stores

- Personalized recommendations
	- Power intent-based search and recommendations with embeddings

- Data processing
	- Add AI to pipelines for content moderation, transcription or text generation

Using Prompt Templates
---------------------
Why use prompt templates?

- Simplifies prompt construction
- Makes prompts reusable and maintainable
- Keeps logic and text clealy separated
- Supports paramterized placeholders like {customerName}

Where can prompt templates live?
---------------------------------
src/main/resource/promptTemplates/userpromptTemplates.st (st => string template)

How to use in code?
--------------------
@Value("classpath:/promptTemplates/userpromptTemplates")
Resource userpromptTemplate

Use with .user() Prompt builder

chatClient.prompt().user(promptUserSpec -> promptUserSpec.text(userpromptTemplate)
					.param("customerNmae",customerName)
					.param("customerMessage",customerMessage)
					.call().content();
					
Prompt Stuffing 
---------------
Prompt Stuffing = giving the LLM an open book before answering a question

- You include contextual data or reference text along with the user's question
- The LLM uses this context to answer the question accurately - even if it was not pre-trained on teh topic
- This technique is also know as in-context learning or retrieval-augmented propmting (when donr programmatically) 
- e.g: internal company policy lookup 

Prompt (Stuffed):
	"According to teh company's HR policy, employees are eligible for 18 days of paid leave annually, Unused leave can 
	be carried over to the next year"

Question:
	How amy paid leaves do employees get each year

LLM Answer
	Employees are eligible for 18 days of paid leave anually
